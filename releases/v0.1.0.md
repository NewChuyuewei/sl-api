# CYW's API v0.1.0

面向 **SCP:SL 14.2.9 / LabAPI 1.1.7** 专用服务器的 LabAPI 扩展框架与插件套件。插件与程序集版本均为 **0.1.0**；本版本不是 EXILED 插件，不能在仅安装 EXILED 的服务器上运行。

## 本次重点

- 框架版本行现可靠出现在服务器最终 `buildinfo` / Mod-Description 输出中。
- 日志会中和不可信文本中的原始控制字符，避免终端控制序列注入与伪造日志行。
- 最终候选 QA-A + QA-A2 合并 **PASS**、QA-B **PASS**；Windows 仅 zip 干净安装、真实第三方 ServerQoL 共存及一次真实回合重启均已验证。

**⚠ Owner action**：本版本无配置键、权限节点或内容 ID 变更。手工部署（直接拷贝 DLL）的服务器请确认 `0CywApi.dll`、`CywApi.Core.dll` 与 `0Harmony.dll` 均已就位。

## Fixed

- 修复框架版本行的注入时机问题。实测启动输出包含 `- CywApi by chuyuewei [0.1.0]: …` 与 `CYW's API v0.1.0`，服务器所有者可直接从最终 `buildinfo` / Mod-Description 输出确认框架版本。

## Security

- 日志输出中和原始控制字符（ESC / CR / BEL / C1 / DEL 等）：不可信文本无法再向服务器控制台注入终端控制序列或伪造日志行。
- 新增 `CywLog.EscapeData(...)`，供数据字段在嵌入日志前安全转义；日志消息保留换行 LF，数据字段连 CR/LF 一并转义。

## Changed

- 身份元数据统一为 `chuyuewei`（作者、公司、版权，含 `LICENSE`）。
- `LabApi` 程序集引用不再 publicize；框架仅针对 LabAPI 公开接口面编译，不依赖框架内部实现。
- 补丁注册表 API 契约已文档化；撤销补丁（unpatch）时输出 INFO 审计行。共享 Harmony ID `cywapi.framework` 为框架保留，第三方插件请勿占用。

## Internal

- 测试用例由 26 增至 45；`CywApi.Core` 行覆盖 113/113（100%）、分支覆盖 90/92（97.83%）。
- `LangVersion` 单一来源化为 `14.0`，由 `Directory.Build.props` 统一钉住。
- 补丁器失败路径可重试，部分加载时输出诊断信息。
- 模块禁用路径加固：禁用不再清空模块注册表，且禁用路径永不抛异常。

## 下载、校验与安装

**发布文件：** `CYW-Plugins.zip`

**SHA256：**

```text
2C69FBD21F17799E10A480947421711BAE1CB10424F5EED3C9A720C3EA426834
```

1. 将 `CYW-Plugins.zip` 解压到 LabAPI 根目录（例如 `%APPDATA%\SCP Secret Laboratory\LabAPI\`）；zip 内部即 LabAPI 布局，无需再嵌套一层目录。
2. 确认以下文件就位：
   - `plugins/global/0CywApi.dll`
   - `dependencies/global/CywApi.Core.dll`
   - `dependencies/global/0Harmony.dll`（Lib.Harmony 2.2.2）
3. 启动服务器。配置文件位于 `configs/<port>/CywApi/config.yml`，与插件的 `properties.yml` 同目录。
4. 需要停用时，在同目录 `properties.yml` 设置 `is_enabled: false` 并重启；恢复为 `true` 后再次重启即可重新启用。

完整安装、依赖、配置键与故障边界见仓库 `README.md` 的「服务器所有者快速开始」「依赖与第三方」章节。

发布包仅包含框架插件、第一方 Core、0Harmony 与安装说明，不含游戏或 LabAPI 框架 DLL。**验证用临时探针 DLL 与用于共存验证的第三方 ServerQoL 均不在发布包内。**

## 当前构建透明性声明

当前启用 Compatibility 与 Patching 模块，提供游戏版本检查/告警、向最终 `buildinfo` / Mod-Description 添加框架版本行，以及框架日志和补丁管理。当前构建**未随附或应用任何补丁类**（实机汇总为 `+0 applied, 0 failed, 0 skipped`），不新增命令或权限节点、自定义角色/物品，不收集玩家数据，也不包含其他影响玩法的行为。

因此，`CywPlugin.IsTransparent` 仅针对上述当前 0.1.0 构建为 `true`；这不是对未来版本的透明性承诺。
